# 🌍 International Career Attractiveness Index

An exploratory data analysis project that investigates the factors influencing the attractiveness of countries for international career opportunities.

## 📌 Overview

The **International Career Attractiveness Index** explores and compares countries based on various economic, social, and quality-of-life factors that influence professionals when considering international career opportunities.

This project applies data analysis techniques to identify trends, evaluate contributing factors, and gain insights into what makes a country an attractive destination for global talent.

---

## 🎯 Objectives

The objectives of this project are:

- Analyse factors that influence international career attractiveness
- Compare countries based on relevant indicators
- Identify trends and relationships within the dataset
- Apply data analysis techniques to extract meaningful insights
- Visualise findings to support data-driven conclusions

---

## 📊 Methodology

This project follows a structured data analysis workflow:

### 1. Data Collection
- Gather relevant datasets containing country-level indicators
- Combine multiple sources to analyse different aspects of career attractiveness

### 2. Data Cleaning & Preparation
- Handle missing and inconsistent data
- Format datasets for analysis
- Prepare variables for exploration and visualisation

### 3. Exploratory Data Analysis (EDA)
- Analyse patterns and relationships between variables
- Identify key factors affecting country rankings
- Generate statistical insights from the data

### 4. Data Visualisation
- Create visual representations of findings
- Use charts and graphs to communicate insights effectively

### 5. Analysis & Interpretation
- Compare countries across different indicators
- Evaluate factors contributing to international career attractiveness

## 🚀 Getting Started

### Prerequisites

Ensure Python is installed on your machine.

Install the required dependencies:

```bash
pip install pandas numpy matplotlib jupyter
```

### Running the Project

Clone the repository:

```bash
git clone https://github.com/LeafMonarch/International-Career-Attractiveness-Index.git
```

Navigate into the project directory:

```bash
cd International-Career-Attractiveness-Index
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebooks directory and run the analysis.
